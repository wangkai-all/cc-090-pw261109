# 本地数据抽样实验台

纯浏览器端的数据抽样实验页：选表、选择分层字段与样本量，生成**可复现**的抽样方案，并对照
总体与样本的类别比例、空值率与数值分布。所有计算在本地完成，不上传数据、不修改原表。

## 运行

```bash
# 任选一种静态服务器（ES Modules 不能直接用 file:// 打开）
python3 -m http.server 8080
# 或 npx serve .
```

然后访问 <http://localhost:8080/index.html>，点击「载入演示数据」即可立即体验。

## 测试

```bash
npm test                 # 21 个 Node 单元测试（核心算法，零 DOM 依赖）
```

## 功能与需求对照

| 需求 | 实现 |
| --- | --- |
| 简单随机 / 分层 / 按时间段抽样 | `js/sampling.js` 三种独立算法，统一入口 `runSampling` |
| 同种子同输入结果一致 | mulberry32 PRNG + FNV-1a 盐值哈希；每层/每环节独立随机流，结果按来源行号升序输出 |
| 分层：按比例 / 每层保底可选 | 最大余数法按比例分配（含容量回收）；保底分配先满足 `min(保底, 层容量)` 再分配余额 |
| 某层样本不足 | 报告计划/实际数量与偏差，**绝不复制记录凑数**；保底总和超过样本量时直接报错 |
| 稀有类别偏差 | 分层明细表与类别比例对照图展示样本占比相对总体占比的偏离（百分点） |
| 时间抽样保留连续区间 | 按粒度分桶后整体选取连续块，区间内行全部保留，不打散为随机样本；支持区间数/目标行数两种口径 |
| 空字段提示覆盖范围 | 空列、空值率 ≥50% 的列单独列覆盖面板；分层时空值进入独立「(空值)」层 |
| 时间格式混乱 | 支持 ISO、`YYYY-MM-DD`、`MM/DD/YYYY`、`YYYY/MM/DD`、`DD.MM.YYYY`、紧凑日期、Excel 序列等；无法解析的行排除并给出行号与可解析时间范围 |
| 调整样本量比较统计影响 | 样本量扫描：同种子对多个样本量重跑，折线图展示最大空值率偏差与最大类别比例偏差 |
| 导出带来源行号 | 样本 CSV 首列为 `source_row`（含表头的 1 起行号），附方案元信息注释头；另导出统计对照 CSV 与方案 JSON |
| 不改原表 | 文件只读解析；应用内没有任何写回原文件的路径，导出均为新文件下载 |
| 方案记录输入指纹/参数/种子 | 方案 JSON 含数据集 SHA-256 指纹、行数、列数、算法版本、全部参数与种子 |
| 输入变化后明确失效 | 复现/导入时校验指纹、行数、列数与依赖字段；不匹配即标红失效并明示「不能声称旧样本仍可复现」 |

## 目录结构

```
index.html            页面结构
styles.css            明暗双主题（data-theme 切换）
js/
  prng.js             确定性随机数与无放回抽样
  csv.js              CSV/TSV 解析（引号转义、BOM、分隔符探测）与序列化
  date.js             宽容时间解析与时间桶
  sampling.js         列类型推断、三种抽样、分层分配、方案构建/校验/复现
  stats.js            空值率、类别比例、数值分布对照与样本量扫描
  charts.js           零依赖内联 SVG 图表（含数据表降级与悬停提示）
  fingerprint.js      SHA-256 输入/结果指纹（Web Crypto / node:crypto）
  demo.js             确定性演示数据（含稀有类别、空值、混乱时间格式）
  main.js             DOM 装配与应用状态
tests/sampling.test.js  Node 单元测试
```

## 可复现性说明

- 随机源：`mulberry32(seed32)`，种子经 FNV-1a 归一化为 32 位无符号整数；
  各抽样环节用 `(seed, salt)` 派生独立 RNG，盐值包含层名/粒度/块长等，处理顺序变化不影响结果。
- 结果指纹：对排序后的来源行号（1 起含表头）做 SHA-256，复现时逐位比对。
- 时间统一按 UTC 解析与分桶，规避本地时区差异。
- 算法版本写入方案（`local-sampling-lab@1.0.0`）；版本不一致时复现会给出告警。

## 已知边界

- 仅支持带表头的 CSV/TSV 文本（`.csv/.tsv/.txt`），不支持 Excel 二进制；Excel 可另存为 CSV。
- 大文件（约 10 万行以上）在浏览器中解析与图表渲染会变慢，核心算法本身为 O(n log n)。
